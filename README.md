# Puti-AI | 教室大螢幕 Classroomscreen (自由浮動桌面旗艦版)

> 超越 Classroomscreen 的自由浮動桌面版現代課堂教學平台，融合日系暖心美學（Zen Maru Gothic、莫蘭迪粉彩調色盤、大圓角玻璃擬態）與 Cloudflare Pages 雲端架構。

---

## 🌟 核心特色與亮點升級

1. **全新自由浮動桌面視窗系統 (WindowManager)**
   - **自由拖曳 & 縮放**：支援觸控大螢幕 (大屏電子白板)、iPad 手勢與滑鼠全方位拖曳；右下角自由無段式縮放。
   - **視窗堆疊與管理 (Z-Index)**：點擊任一視窗自動置頂，支援「最小化收合」與「最大化展開」及關閉。
   - **一鍵淨空桌面**：頂部「淨空桌面 / 還原視窗」切換，一秒平滑淡出所有視窗，需要時無損原地還原。

2. **巨大精緻 3D 骰子與 3D 浮雕金幣**
   - **立體象牙骰子**：超大 108px 逼真立體骰子，真實點數排列（大紅心一、黑二三四六點）。
   - **浮雕金幣**：120px 金屬光澤 3D 翻轉動畫金幣，課堂隨機裁決超有儀式感。

3. **巨幅投影 QR Code 放大燈箱**
   - 課堂即時投票、手機搶答器皆提供 **「放大投影 QR Code」** 專屬按鈕，彈出滿版高對比二維碼，教室最後一排學生用平板也能秒掃描！

4. **字體無級放大控制 (A+ / A-)**
   - 黑板公告、隨手便利貼、家庭聯絡簿、作息流程表均提供直覺的字體放大縮小工具，遠距離閱讀清晰無比。

5. **🆕 全新功能：家庭聯絡簿 (Homework & Contact Book)**
   - 國小標準規格：國語、數學、英語、其他、重要叮嚀帶物通知。
   - 自動即時存檔至 `localStorage`。
   - 一鍵複製格式化文字，方便老師秒貼至班級家長 LINE 群組。

6. **🆕 全新功能：課堂搶答神器 (Quick Buzzer)**
   - **現場大螢幕搶答**：第一~四組大按鈕，支援觸碰螢幕或鍵盤數字鍵 `1`、`2`、`3`、`4`。
   - **📱 學生手機/平板線上搶答**：掃碼進入 [`student-buzzer.html`](public/student-buzzer.html)，毫秒級比對誰第一個搶答成功！
   - 自動響鈴、大螢幕閃爍冠軍光環與反應秒數。

7. **完整 28 種全能微工具庫**
   - 涵蓋時間管理、課堂經營、互動遊戲、繪圖圖像與多媒體整合。

## 🚀 本地開發與 Cloudflare 部署

### 本地啟動：
```bash
python -m http.server 8899 --directory public
```
開啟瀏覽器進入 `http://localhost:8899` 即可使用。

### Cloudflare Pages 雲端部署：
```bash
npx wrangler pages deploy public --project-name=puti-classroomscreen
```
