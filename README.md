# Puti-AI | 教室大螢幕 (自由浮動桌面旗艦版)

> 專為台灣智慧黑板與大螢幕課堂量身打造的自由浮動桌面教學平台，融合日系暖心美學（Zen Maru Gothic、莫蘭迪粉彩調色盤、大圓角玻璃擬態）與 Cloudflare Pages 雲端架構。

---

## 🌟 核心特色與亮點升級

1. **全新自由浮動桌面視窗系統 (WindowManager)**
   - **自由拖曳 & 縮放**：支援觸控大螢幕 (大屏電子白板)、iPad 手勢與滑鼠全方位拖曳；右下角自由無段式縮放。
   - **視窗堆疊與管理 (Z-Index)**：點擊任一視窗自動置頂，支援「最小化收合」與「最大化展開」及關閉。
   - **一鍵純淨桌面**：頂部「純淨桌面」切換，一秒平滑淡出所有視窗，回歸黑板或美觀背景，需要時原地無損還原。

2. **🎓 多班級切換與名冊管理（科任跑班首選）**
   - **頂部選單一鍵秒切**：頂部工具列直接提供班級下拉選單（如 501 班、502 班、503 班），進教室一秒切換。
   - **全域小工具即時連動**：切換班級時，**幸運抽籤**、**隨機分組**、**個人計分板** 自動同步更新為該班名冊。
   - **跨電腦匯出／匯入備份**：支援整包 JSON 名冊匯出與匯入，老師在辦公室筆電設定完，到教室大螢幕 1 秒匯入還原。
   - **🔒 100% 本機儲存・零個資上網**：學生姓名、座號與成績完全存放於目前電腦瀏覽器（LocalStorage），絕不上傳外部伺服器，徹底保障校園隱私。

3. **🖥️ 視距無憂：大螢幕全域字級與情境存檔**
   - **全域字級等比縮放**：提供標準 16 / 中 20 / 大 24 / 特大 28，專為 75~86 吋智慧黑板量身優化，最後一排學生依然看得清清楚楚。
   - **自訂情境一鍵保存**：內建「專注、小組競賽、放學」快捷佈局；任意擺放工具視窗後，點擊「+ 存情境」即可永久保存。

4. **🖼️ 12 款精美情境桌布與自訂背景**
   - 內建教育科技 (預設)、黑板、海邊、天空、草原、花海、宇宙、銀河、山岳、海洋世界、呆萌狗仔、可愛小貓等 12 款精選主題。
   - 支援自選上傳本機班級照片或輸入圖片網址。

5. **📱 課堂手機互動（學生免裝 App）**
   - **課堂搶答神器**：手機掃碼連線，大螢幕顯示實際連線狀態；教師解鎖後進行毫秒級搶答，大螢幕唱名加分。
   - **課堂即時投票**：支援單選/多選、盲投開箱長條圖與題庫匯入匯出，內建「每台裝置一票」防重複投票機制。
   - **巨幅投影 QR Code**：一鍵彈出滿版高對比二維碼，教室最後一排也能秒掃描。

6. **⏱️ 時間與考程全面自訂升級**
   - **計時器 & 視覺計時器**：支援自由輸入自訂倒數分鐘與秒數，搭配 +30 秒 / +1 分鐘微調與醒目鐘響。
   - **定時考試日程倒數計時器**：防呆時間校驗（自動檢查開始與結束時間先後）、大字科目倒數與考程自動切換。

7. **🎲 巨大精緻 3D 骰子與 3D 浮雕金幣**
   - **立體象牙骰子**：超大逼真立體骰子（1~3 顆），真實點數排列（大紅心一、黑二三四六點）。
   - **浮雕金幣**：120px 金屬光澤 3D 翻轉動畫金幣，課堂隨機裁決超有儀式感。

8. **🛠️ 完整收錄 33 項全能微工具庫**
   - **時間與考程 (9項)**：計時器、視覺計時器、競賽碼錶、數位時鐘、教室月曆、班級功課表、作息流程表、考試日程計時器、重要日子倒數。
   - **常規與秩序 (4項)**：紅綠燈、工作符號、課堂分貝儀、教室白噪音。
   - **互動評量與激勵 (9項)**：幸運抽籤、隨機分組、小組記分板、個人計分器、課堂搶答神器、課堂即時投票、骰子硬幣、猜拳對決、課堂獎勵貼紙。
   - **板書展示與多媒體 (11項)**：塗鴉白板、家庭聯絡簿、跑馬燈廣播、電子便利貼、圖片展示、PDF 閱讀展示、快速 QR Code、超連結導航、課堂影片播放、網頁嵌入 (Embed)、實物投影相機。

## 🚀 本地開發與 Cloudflare 部署

### 本地啟動：
```bash
python -m http.server 8899 --directory public
```
開啟瀏覽器進入 `http://localhost:8899` 即可使用。

### Cloudflare Pages 雲端部署：
```bash
npx wrangler pages deploy public --project-name=puti-classroomscreen
```
